# 하이미디어아카데미 수강 후기

K-Digital 심화과정 수강 후기 7건을 제공된 `kdigital-reviews.html`에서 옮기고, 본인이 제공하고 공개를 요청한 김ㅇ나의 취업 후기 1건을 추가한 정적 사이트입니다. 기존 후기 제목·본문·날짜는 원본 데이터를 유지합니다. 작성자 이름은 요청받은 마스킹 표기를 사용합니다.

## 파일

- `index.html`: 페이지 구조와 공유 정보
- `styles.css`: 반응형 디자인
- `reviews.js`: 후기 데이터 (`window.HIMEDIA_REVIEWS`)
- `app.js`: 검색, 주제 필터, 정렬, 상세 보기
- `assets/`: 하이미디어 로고, 프로젝트 발표 사진, 한글 폰트

빌드 단계나 서버, 별도의 API 없이 작동합니다. `index.html`을 열거나 정적 웹 서버에서 확인할 수 있습니다. 자산 경로는 상대 경로로 작성되어 GitHub Pages의 프로젝트 하위 경로에서도 작동합니다.

## GitHub Pages

저장소 `Settings → Pages`에서 `Deploy from a branch`, `main`, `/ (root)`를 선택합니다.

게시 주소: https://sio60.github.io/sio60.github.io-review/

대표 주소: https://himedia-gangnam.kr/reviews/

GitHub는 소스와 미리보기를 유지합니다. 운영 도메인에는 공개 파일과 `assets/`만 배포하며 `.git` 및 작업 파일은 포함하지 않습니다.

## 후기 추가

`reviews.js`의 `reviews` 배열에 고유한 `id`, `title`, `body`, `course`, `author`, `publishedAt`, `tags`를 추가합니다. 본문 문단은 `\n\n`으로 구분합니다. 지원하는 주제는 `커리큘럼`, `프로젝트`, `강사진`, `성장 이야기`입니다. 게시 전 후기 사용 동의와 개인정보를 확인하세요.

상단 인용문은 제공된 후기 본문의 일부입니다. 발표 사진은 프로젝트 현장 자료이며 특정 후기 작성자의 사진으로 연결하지 않습니다.

## 취업 스토리 카테고리

고졸 / 비전공자 / 전공자 카테고리가 준비되어 있습니다. 김ㅇ나·김ㅇ현·익명 AI 서비스 후기와 사용자가 확인한 김ㅇ아·안ㅇ영은 비전공자로 분류했습니다. 김ㅇ경은 사용자의 정정에 따라 전공자로 변경하고 제목과 본문의 자기소개도 일치시켰습니다. 김ㅇ나는 대학 중퇴·최종학력 고졸이라는 요청에 따라 고졸 카테고리에도 함께 노출합니다. 나머지 익명 후기 2건은 정보 확인 전까지 전체 스토리에만 노출합니다. `background`는 단일 분류, `backgrounds` 배열은 여러 카테고리에 동시 노출할 때 사용합니다. 전체 목록에는 후기를 중복 생성하지 않습니다.
